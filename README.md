### 📱 Foco nos Projetos & Expo Ecosystem
> Meus projetos exploram o potencial máximo do **Expo**, desde a estruturação de navegações complexas até o deploy automatizado.

* **Expo Router:** Implementação de navegação baseada em arquivos para fluxos mobile limpos e intuitivos.
* **EAS (Expo Application Services):** Utilização de *EAS Build* para compilação na nuvem e *EAS Update* para entregas ágeis.
* **APIs Nativas e JavaScript:** Integração avançada de recursos de hardware do dispositivo com código limpo e performático em JS/TS.
